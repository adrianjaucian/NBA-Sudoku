TEAMMATE

Each cell must match its row team, column team, and 2×2 box team. Those labels are the only clues.

Player bank

Place each name once. A player fits a cell only if they played for that cell’s row, column, and box teams.

Rules

  • No starting players — only the team labels are clues.
  • Every row, column, and 2×2 box has a franchise label.
  • A player in a cell must have played for all three labels that cover that cell.
  • Use each bank player exactly once. Each puzzle has exactly one solution.
